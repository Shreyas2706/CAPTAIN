# 🧠 Captain – Your JavaScript Desktop Assistant

Captain is a voice-activated desktop assistant built using JavaScript, designed to streamline your daily tasks and enhance productivity. With speech recognition and smart response capabilities, Captain listens, understands, and acts—just like your digital sidekick!

---

## 🚀 Features

- 🎙 Voice Command Recognition  
- 🧾 Responds via Voice and Text  
- 🗂 Opens applications, websites, and files  
- 📅 Tells date & time  
- 🌐 Provides quick search functionality  
- 🔊 Text-to-Speech responses  
- 🔧 Easy to customize and extend  

---

## 🛠 Tech Stack

- JavaScript (Vanilla)  
- Web Speech API (for Speech Recognition & TTS)  
- Node.js (optional for advanced integrations)  
- HTML + CSS for UI (if applicable)
